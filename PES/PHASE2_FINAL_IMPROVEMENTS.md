# PES Phase 2: Final Improvements Before Phase 3

## Issues Identified (from Review)

### 1. ❌ Cannot select winning prompt to run new evolution
**Issue**: No way to use the winning prompt as baseline for next iteration
**Fix**: Add "Use as Baseline" button on winner card

### 2. ❌ Cannot see the actual prompt text
**Issue**: Prompt changes are not visible - can't see what was modified
**Fix**: Add collapsible prompt text display for each variant with diff highlighting

### 3. ❌ Missing metrics on All Variants Comparison
**Issue**: Some variants show "N/A" for metrics
**Fix**: Ensure all variants have complete simulation data before aggregation

### 4. ❌ Key Insights are hardcoded  
**Issue**: Insights appear to be generated by AI but concern they might be hardcoded
**Reality**: They ARE AI-generated by ONESEEK via `aggregateInsights()` in debate-analyzer.js
**Fix**: Add better debugging/transparency to show insights are AI-generated

### 5. ❌ White text on white background in Key Insights
**Issue**: List items (`<li>`) have no text color specified
**Fix**: Add `text-gray-700` class to all `<li>` elements

### 6. ✅ Philosophy: AI-driven, not hardcoded
**Confirmed**: System IS AI-driven:
- `analyzeSingleDebate()` uses ONESEEK to analyze each debate
- `aggregateInsights()` uses ONESEEK for meta-analysis
- `generatePromptVariants()` uses ONESEEK for variant generation
- Only fallbacks use heuristics when AI fails
